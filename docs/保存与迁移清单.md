## 不需要搬走的内容

- `.venv`、`__pycache__`、测试缓存：可以用 Python 和依赖声明重建。
- HF 下载缓存：首次联网运行会按固定仓库版本重新获取；动作加载失败可检查网络。
- 网吧上的设备编号、COM 端口和窗口编号：新电脑需要重新选择，照搬可能选错设备。
- 开发时的多份 `.env.before-*`、运行日志和私人对话记录：不纳入源码仓库。

## 到自己的电脑恢复

1. 安装 Windows 版 Python 3.12 64 位与官方 Reachy Mini Control。
2. 克隆 GitHub 仓库，或解压源码 ZIP；目录路径不要指向网吧机器。
3. 运行 `Setup-Companion.cmd`；安装依赖后，会生成本地 `.env` 和偏好设置。
4. 在本地 `.env` 填入密钥。模型、地址、声线选择可参考随仓库提供的模板；服务商可能调整可用模型。
5. 连接机器人并启动官方控制服务，运行 `Start-Companion.cmd`，打开 8768 页面。
6. “设备与连接”中重新连接本体、选择麦克风与扬声器、试听并测试动作。
7. 进入实际对局，选择游戏窗口并确认英雄。核对长期装备知识与 HF 动作已加载；英雄确认后等待出装预加载。
8. 可选运行 `.\.venv\Scripts\python.exe -m pytest -q` 检查软件测试。
